| Ribbon       | 5                       |           1 |

|              | 3 (red with writing)    |           3 |
|              | 3 (blue with writing)   |           3 |
|              | 3 (red without writing) |           3 |

| Junk         | 10                      |           1 |
|              | 1 (after 10)            |           1 |
- 10 Junk = 1 point
- 3 red ribbons with writing = 3 points
- 3 bright (including rain) = 5 points
- February, April, August Animals = 5 points
